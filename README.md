# CTS 视频全流程发布包 · Codex 版

Skill 名称：`video-release-workflow`，版本：`1.0.0`。

把“选题/口述 → 文案或大纲 → 自己拍摄 → 回传视频 → 精剪、字幕、动画与音效 → 封面、标题话题 → 多平台上传检查 → 本条确认后发布”放进同一个 Skill。

支持在任意阶段继续，也可以只要封面、标题或精剪。接收者使用自己的素材、偏好、账号和工具，不需要作者的 CTS、账号数据或私有知识库。

## 使用

安装后，可以这样开始：

> 用 $video-release-workflow 处理这条视频，从当前阶段继续，制作可检查的完整发布包，上传检查后等我确认发布。

随口拍摄：

```text
$video-release-workflow
我要讲一个真实经历。先给我开头原句、推进要点和结尾意思；我自己拍，录完再发你。
```

处理原片：

```text
$video-release-workflow
这是拍好的原片。保留完整观点，删口误和没作用的停顿，加居中单行字幕。
新动画先给预览，不要背景音乐。再做双封面和一行标题话题。
```

上传准备：

```text
$video-release-workflow
用这个已确认发布包，准备抖音、视频号、B站、小红书。
核验我自己的账号，上传填好后给我检查结果，等我针对这条确认发布。
```

## 运行依赖

- 写稿与规划：可用的 Codex。
- 基础媒体脚本：Python 3、FFmpeg/FFprobe；字幕与封面需要本机可合法使用的字体和 FFmpeg 对应滤镜。脚本不会自动安装依赖。
- 转写：用户提供的字幕，或已配置并授权的语音识别工具；没有转写能力会说明缺口，不把拍前稿冒充实拍转写。
- 复杂动画：本机可用的渲染环境，可选 Remotion；本包不捆绑其依赖。
- 网页上传：Codex 实际可用的浏览器控制或平台连接器，以及用户正常登录。控制工具不可用时仍可制作本地发布包，但不能声称已上传或发布。

本包没有其他 Skill 的强制依赖，不附字体、音乐、音效文件、第三方付费课程或其他 Skill 副本。
