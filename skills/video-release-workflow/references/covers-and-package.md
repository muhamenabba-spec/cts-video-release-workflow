# 封面与发布包装

## 真实人物与分别排版

从本条原视频选清晰自然的一帧，保存来源时间和原帧。没有真人原片时不生成“用户本人”代替；可用合法的非人物图解。

原始人物图层锁定：允许等比例缩放、位置移动、合理裁切；禁止改脸、美颜重绘、凭空补手或换服装。使用蒙版时检查头发、手臂、手指和躯干；分割不好退回完整原帧版，不用粗硬描边遮缺失身体。画板、椅子外缘不是人物轮廓。

已有确认风格沿用。没有风格时先提议简洁高对比版，给实际预览，不默默建立永久偏好。字体适当粗、手机缩略图可读。文字不挡关键表情、产品和白板证据。

一般可建议竖版 1080×1440、横版 1440×1080；这只是可交付的两个版本，不是官方上传规格承诺。分别排版，同一真实人像不拉伸。目标平台需要另一比例时派生留边/重新排版，保留确认源图；裁切预览逐字检查，尤其是标题、握笔手、产品。

`media.py cover` 是保留整张原帧、下方独立标题区的基础封面工具，不做人像分割、描边或 AI 重绘。可供依赖较少的新用户使用；用户指定更复杂样式时需用可编辑图层工程另做。

```powershell
python "$skillDir/scripts/media.py" cover "原帧.png" --text-file "封面文字.txt" --font-file "合法字体文件.ttf" --output "竖封面.png" --width 1080 --height 1440
python "$skillDir/scripts/media.py" cover "原帧.png" --text-file "封面文字.txt" --font-file "合法字体文件.ttf" --output "横封面.png" --width 1440 --height 1080
```

文字文件最多两行；封面字与视频字幕分开。脚本只保证不拉伸，不替代画面审美和手机可读验收。

## 标题与话题

从成片中的真实冲突、对象或收获提炼标题。不要为了点击编造成交、收入或结果。话题对应受众、主题和场景，不加不相关热词。

默认交一个主推版本，需要选择时才给少量备选。用户已确认标题/封面文字/话题就原样保留；平台长度导致实质改写须让用户看变化。

对外交一行，便于复制：

```text
标题原文 #核心受众 #本条主题 #具体场景
```

没有额外配文需求就不再补一段发布配文。填网页时按真实字段分配标题与标签，不能把整行机械塞进所有平台标题框，也不能创建重复标签。

## 完整发布包

按 [release 模板](../assets/release.example.json) 填真实路径和确认状态。`bundle.py pack` 输出：

- 当前 MP4；竖、横 PNG；一行标题话题。
- 有字幕时附字幕；有原稿时附对应稿件；真实验收记录。
- `manifest.json`：work_id、相对文件路径、SHA256、字节、媒体探测和逐平台空状态。

先跑 `check`，再实际看成片和封面。缺素材/待确认状态必须保留；模板中的 null 不可以被助手猜成用户已确认事实。不得把 manifest 内的 true 当平台或版权证明。

项目中另外保存可编辑工程、封面图层、源帧、时间线/音效计划和确认记录，不必重复复制巨大依赖到发布包。
