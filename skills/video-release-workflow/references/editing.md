# 剪辑、字幕、动画与音效

## 先检查真实原片

用 FFprobe 看时长、尺寸、方向、帧率、音轨；抽开头、关键句、结尾的真实帧。保留原片哈希。检查已有烧录字幕、水印、手机 UI 和遮挡，不能用比例猜安全区。

转写须有时间码与来源。先复用已校准的字幕/ASR，不重复付费。关键业务名、金额、否定词回到原声/画面核验；不清楚标记待核实。标题文字不等于口播原话。

## 语义剪辑，再落切点

以意义完整的段落为单位，标记观点、前提、证据、案例、承接、限制和情绪落点。保存：原片起止、原话、作用、保留/删除/移动、理由、输出顺序、核验状态。

删除后检查：主语、对象、因果、时间和否定是否改变，指代是否仍能理解，原来的问答是否配对。不能把不同问题的回答拼成新立场。重复句可能是结尾回应，不按字符串重复一律删。

必要时前置原片已有的冲突或结果；前置后正文仍须证明。新连接句若没拍，只能列补录需求或明确的编辑说明，不合成不存在的原声。

用户让删停顿/口误可直接精剪；新实质重排先给简短顺序和逐字稿等确认。落切点时保护字头字尾和自然呼吸；保留用于思考/选择的必要停顿。按源时间→输出时间映射重新对齐字幕和音效。

基础切点结构见 [示例](../assets/edit-plan.example.json)。脚本 `media.py cut` 只执行明确的片段次序，输出时间映射；不能自动判断哪句话值得删。

## 字幕

字幕写实拍真实发言，改明显转写错误，不拿更漂亮的文案替代已经说过的话。完整口播可读，按短语拆 cue，不截词、不一字一行。

默认建议单行、每 cue 不超过 12 个可见字符、横向居中；用户偏好或外语可修改字数。长句分成连续短语，而非缩到看不清。位置按当前构图和平台预览选择；固定 0.75 高度只是脚本初排值，不是官方安全区。

有可读烧录字幕时不再叠字幕。把真人缩小成画中画会让原字幕缩小：可以保留真人大画面并在空白处叠图解；或用无烧录原片，加独立全尺寸字幕。不得用新字幕盖住旧字后称已修好。

字体从本机合法资源选，核验中文字符和字体实际名称。不随包分发第三方字体。脚本生成 ASS 并烧录字幕，也应保留 cue JSON 与可编辑 ASS；需要 SRT 时另导出。脚本拒绝换行和重叠 cue，不代表视觉位置已验收。

`captions.json` 示例（时间均为精剪后秒数）：

```json
[
  {"start": 0.1, "end": 1.4, "text": "先看真实的问题"},
  {"start": 1.5, "end": 2.9, "text": "再决定怎么解决"}
]
```

## 重点动画与画中画

先给一个静帧或几秒预览核对样式。画幅沿用本条确认，不因为某个模板是竖屏就改横屏视频。人物、主图解和字幕分别留区域，实际检查，不把内容挤到平台按钮区。

以台词触发动画：关键字说到时划线/变色，比较出现时再亮数字，提问后给理解时间。稳定文字不持续漂移，退出后不残留旧字。画重点可以用马克笔笔触，但不遮文字笔画。

复杂讲解先做“此刻观众知道什么→新增什么→画面证明什么”的分镜，再写实现。Remotion 可作为可选环境：使用帧驱动、确定性的动画；所有音画资源在渲染前定位；先预览关键帧，再完整渲染。依赖安装、商业服务或付费素材需另获授权。

不捆绑 Remotion 工程依赖；没有 Remotion 仍可用 FFmpeg 完成基础精剪、字幕和声音。基础静态字幕不冒称复杂动画已完成。

## 音效不是背景噪声

先标语义触发点，再选声音。少量、短促、低于人声；不在每个 cue 上塞一个提示音。用户不要 BGM 就不加。只使用可合法使用的本地/授权素材，保存文件来源、许可、音量和输出时间。

| 画面作用 | 可考虑的声音 | 注意 |
| --- | --- | --- |
| 单个强关键词弹出 | 短单击/低频轻碰撞 | 同说到该词的时点，不用长旋律 |
| 疑问或反转 | 非人声上扬疑问音 | 不装成另一人发言 |
| 划线或马克笔 | 短笔划/摩擦声 | 跟笔触运动同起同落 |
| 按钮/状态确认 | 轻点击或正确提示 | 不让操作音比原声响 |
| 卡片进出/转场 | 短 woosh | 真有移动才配，不空响 |
| 数字增长/选择倒计时 | 克制滴声或短节拍 | 根据理解节奏，不抢口播 |

这是一组选音判断，不声称包含剪映同名原声。仅搜索结果、文字名称不能当可用音效；必须取得合法文件并试听。不能从别人的视频中直接抽音乐/独特人声来分享。

`sfx-plan.json` 示例：

```json
{
  "events": [
    {"file": "licensed-click.wav", "at": 1.5, "gain_db": -14,
     "authorized": true, "source": "用户授权素材", "cue": "关键词出现"}
  ]
}
```

时间用精剪后时轴。`authorized: true` 必须来自已取得授权/明确许可，不能为了脚本通过随便写。`media.py mix` 会拒绝未授权标记、越界时点和不存在的音频；它不判断权利真假、听感或语义匹配。

## 渲染验收

1. 技术：时长、方向、分辨率、音轨、切点和源哈希；全片解码检查，无截断输出。
2. 视觉：实际查看首屏、最长字幕、重点动画峰值、进出场、画中画、结尾；手机尺寸下能读。
3. 声音：听原声与混音，查卡字、突变、关键词对齐、音量、结尾断声；无法试听明确未听验，不宣布听感很好。
4. 内容：论证完整、数字正确、必要限制在、编辑说明与原话分开。

用户只改某处时只改对应版本，不重写整个确认稿或重做无变化封面。保留可编辑工程、字幕和计划，成片链接指向唯一当前版本。
