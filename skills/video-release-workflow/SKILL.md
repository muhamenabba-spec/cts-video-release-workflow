# 视频全流程发布包

把用户的真实材料变成能播放、能检查、能继续修改的作品，以及可直接使用的发布包。用户负责拍摄；Codex 负责已授权的其余环节。采用当前用户自己的定位、账号和风格，不继承本包作者的业务、案例、账号或私有系统。

## 先定位本条，再选择阶段

先读当前对话、工作区规则和已有项目记录。已有选题、原片、确认稿、工程或发布包就继续使用；不要要求从头填写资料，也不要按“最近一个文件”猜作品。

确认当前请求属于：写稿、等待拍摄、处理原片、修改成片、制作包装、上传准备、确认后提交或发布后登记。只做当前所需的阶段；用户只要封面或标题，不能因此剪视频或打开发布页。用户已发布的平台跳过提交。

信息缺口会改变账号、内容、画幅或授权时，一次问一个问题。低风险细节采用明确标注的默认建议；不能用提问代替已能执行的工作。

新项目可运行 `scripts/bundle.py init` 建立唯一 work_id。项目存用户工作区，不存 Skill 安装目录。读取 [项目与工具](references/project-and-tools.md)，按需复制 [偏好模板](assets/profile.example.json)；它是待确认配置，不是已授权账号列表。

## 分阶段执行

### 1. 写文案或拍摄大纲

读 [文案与拍摄](references/content.md)。明确本条观众、要表达的一个主要观点、真实证据和观看理由，再写自然的口播。不能把对标作者的经历换成“我”。

提词器口播交完整稿；随口拍摄交“开头原句＋几条推进要点＋结尾意思”，完整版可作为备用。口述稿只要求改错字时不重写观点。保存确认记录，等用户回传视频；没有原片不能假称拍摄或剪辑完成。

### 2. 接收实拍、剪辑和声音

读 [剪辑、字幕与音效](references/editing.md)。探测媒体、检查原声和关键帧，复用已有转写。转写不确定的项目名、数字、否定句须回听或询问，不凭文稿覆盖实际发言。

先做带原片时间码的语义剪辑清单，再实现剪辑。删口误、无作用的停顿和重复，不裁掉字音、证据或必要限制。实质重排、新画中画和未确认视觉风格先交短预览；已有确认顺序或“直接精剪”授权不重复索要同一确认。

字幕、重点动画和音效与词句同步，不覆盖人脸、烧录字幕、图解或平台控件。现有字幕可读时避免再叠一层。用户明确不要配乐就不加配乐，不克隆第三方声音。

基础媒体处理可用随包脚本 `scripts/media.py`；复杂动画用 Codex 编写可编辑工程并实际渲染。脚本不能代替内容判断、语音识别、人像分割或 Remotion。依赖不具备时按参考中的降级方式交付，不冒称做了动画。

### 3. 封面、标题话题与发布包

读 [封面与包装](references/covers-and-package.md)。从本条真实原片取清晰帧；保留原始人物，不 AI 重绘或补手补脸。已确认封面文字逐字沿用。横竖封面分别排版，不能把竖图拉伸成横图。

标题、开头、封面与正文兑现同一个承诺。给一行可复制的“标题 #话题 #话题”，默认不附额外配文。版式服从用户当次要求；首次没有偏好时，可提议 3:4 与 4:3 双封面，不宣称是平台通用硬规格。

生成真实 MP4、PNG、字幕文件（如有）、可编辑工程、剪辑记录和验收记录。用 `scripts/bundle.py pack` 整理发布包，再运行 `check` 验证文件哈希。技术校验、人工视听验收、用户确认和网页发布分别记录。

### 4. 多平台上传与确认后发布

仅用户要求上传或走发布流程时读 [平台发布](references/publishing.md)。本包支持抖音、视频号、B站和小红书，但接收者的默认平台及各平台账号须由本人确认，不能把模板清单当发布授权。

使用当前 Codex 实际可用的浏览器或平台连接器，先读其完整操作说明并核验当前页面。登录、验证码由用户完成，不读取密码、Cookie 或绕过连接故障。

上传本条确认文件，填写标题话题、封面和真实来源声明，检查预览。符合原创条件且用户要求时，勾选视频号与小红书的原创声明并读回；“个人观点”或 AI 内容标识不是原创声明。

展示本条作品、账号、版本和各平台检查结果，等用户针对本条明确确认发布，再点击最终按钮。收到确认后不重复索要同一权限；账号、文件或实质包装改变后重新展示。提交状态未知，先查作品列表，禁止盲重试造成重复作品。

逐平台核验并记录：填充完成、提交成功、审核中、后台已发布或公开可播放。点击按钮不等于正式发布，某个平台完成不代表全部完成。

## 交付与边界

- 交付当前成片、双封面（或本条指定版本）、标题话题一行、发布包路径及真实状态；不只交源码，不自动导出 PDF。
- 原素材只读；衍生版本另存，当前版本用项目指针标记。禁止清整盘、删原片或打包登录资料。
- 未安装其他 Skill 仍能执行本包的基础流程；相关方法 Skill、Remotion、ASR、CTS 等都是可选增强，不捆绑私有路径、密钥或付费接口。
- 预测是可选环节：无本账号可比样本就只给内容风险判断，不捏造播放区间；发布后不能补锁发布前预测。
- 复盘和定时自动化仅在用户另行要求且产品工具可用时配置。保存时间表不等于后台已启用；不新建重复执行器。
- 页面、媒体、权利或重要词句无法核验时，保留已有成果，明确当前阻塞和缺少的最小材料。

共享包只包含本 Skill 的指令、模板和自编脚本。用户自己的作品、账号配置、检查截图和发布记录留在其工作区，不进入 Skill 分享包。
